# 🆕 Changelog

## [Unreleased]

- Группы вкладок: именованные наборы вкладок с цветом и иконкой для организации по задачам. Группу можно закрепить в закладках, она открывается в один клик, можно открыть несколько экземпляров одной группы. Группы вкладываются друг в друга, сворачиваются, перетаскиваются по панели наравне с вкладками, принимают вкладки через меню и дроп на заголовок. ПКМ по группе в закладках удаляет шаблон, меню группы содержит Delete group.
- Общий диалог иконки для вкладок и групп: URL, локальный файл, тип источника верифицируется.
- Перетаскивание вкладок и групп по панели: дроп вставляет перетаскиваемое перед целью, элемент-плейсхолдер показывает место.
- `Minimize`/`Unminimize` вместо pin: вкладка схлопывается до иконки и остается на своем месте.
- Меню панели на всей области от кнопки `+` до кнопок окна.
- Кнопки окна и меню вровень с вкладками.
- Фон закладок совпадает с панелью вкладок.
- Нативный фон view под тему без белого флеша при создании вкладки.
