# 🧩 Konstruktor

Мощный браузер для пользователе и разработчиков, увлечённых кастомизацией. Это браузер-конструктор, который является фреймворком + набором стандартных компонентов поверх Electron.  

## ℹ️ Общие сведения

**💻 Целевые платформы:** ПК (Windows). Дальше больше.  
**⚙️ Требования к системе:** Node.js 22.13+ или 24.13+, npm 11.19+.  
**🧰 Основной стек:** Electron 44, Vue 3, TypeScript, Vite, electron-vite. Окно вкладки (веб-страницы) — WebContentsView, интерфейс браузера — кастомизируемые Vue SFC компоненты.   
**🌍 Языки:** Английский, Русский. Расширяемый реестр языков.  

## ⚡ Использование

### 🚀 Быстрый старт 

```sh
npm ci               # установки зависимостей проекта строго по lock файлу
npm run dev          # запуск Vite-сервера и горячая перезагрузка
```

### 📦 Подготовка

```sh
npm ci               # установки зависимостей проекта строго по lock файлу
# или
npm install          # нужен только когда зависимости менялись и lock-файл обновился.
```

### ▶️ Сборка и запуск

```sh
npm run dev          # запуск Vite-сервера и горячая перезагрузка
# или
npm run build        # сборка приложения
npm run preview      # запуск собранного приложения (после build)
```

### ✅ Проверки и стиль

```sh
npm run typecheck    # vue-tsc --noEmit
npm run lint         # eslint . — ошибки в src/
npm run format       # prettier --write . — переформатировать файлы
npm run clean        # удалить out/
```

## 🎨 Кастомизация

Доступны четыре уровня кастомизации. Уровни различаются по сложности и мощности, а вместе с ними растёт и требуемая квалификация: от обычного пользователя до продвинутого разработчика.

| Уровень | Кому доступен | Что позволяет |
|---|---|---|
| 🎨 Кастомизация стиля готового браузера | Пользователь | Браузер предоставляет широкие возможности настройки внешнего вида без правки кода. |
| 🖼️ No-code кастомизация компонентов браузера | Продвинутый пользователь | Сборка браузера расстановкой и редактированием его компонентов в утилите Collage (WIP). |
| 🔧 Кастомизация компонентов браузера | Разработчик | Модификация существующих компонентов или разработка своих. |
| 🛠️ Полная свобода | Продвинутый разработчик | Модификация и разработка не только компонентов, но и core-систем браузера. |

> 🤖 Не воспринимайте эту таблицу слишком серьёзно, условного разработчика может заменить продвинутый пользователь с AI-агентом. Творите, пользуйтесь, распространяйте!
