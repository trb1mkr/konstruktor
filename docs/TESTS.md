# 🧪 Тесты

Документ описывает проверку изменений в проекте: что и как проверяется, где границы проверки и как запускать UI.

## 🧰 Проверка

`npm test` — алиас `npm run typecheck`: тестового фреймворка в проекте нет, проверка идёт через типы. Считать его успешным прогоном нельзя. Проверка изменений в UI идёт через `npm run dev`.

## 🎨 Форматирование

Стиль кода задаёт prettier (`.prettierrc.yml`), разбор ошибок — eslint (`eslint.config.js`). Форматирование и проверка разделены намеренно: `lint` не должен спорить с `format`.

Сама проверка стилей не входит в проверку изменений: `npm run format` переписывает файлы через prettier, `npm run format:check` только сообщает о расхождениях. Перед коммитом прогонять `format` не нужно — реформат делается отдельным коммитом, иначе правка прячется в косметике.
