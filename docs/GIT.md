# 🔀 Правила работы с git

Документ регламентирует правила использования системы контроля версий.

## 🌿 Имена веток

**Правила:**

- Ветки стоит называть по схеме feature/context.
- В качестве разделителя в имени контекста предпочтительно использовать "-"
- Префикс задаётся аббревиатурой из списка типичных действий

**Пример**: ft/address-bar

**Список префиксов**:

| Аббревиатура | Полное имя    |
|--------------|---------------|
| ft           | feature       |
| fx           | fix           |
| hfx          | hotfix        |
| doc          | documentation |
| rf           | refactoring   |
| test         | test          |
| rel          | release       |
| sty          | style         |

## 💾 Коммит

**Правила:**

- Если требуется придумать название коммита, то стоит придерживаться стиля предыдущих коммитов
